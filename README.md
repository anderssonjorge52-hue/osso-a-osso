# Osso a Osso

Anatomia por digitação: uma estrutura acende no corpo e o aluno digita o nome.

- `index.html` — página de vendas com demonstração jogável e preços
- `app.html` — plataforma (login, jogo, progresso, XP, ofensiva e conquistas)
- `config.js` — URL e chave pública do Supabase (a chave pública pode ficar no site; os dados são protegidos pelas regras de segurança do banco)
- `supabase.sql` — tabelas e regras de segurança (já aplicadas no projeto `osso-a-osso`)
- `termos.html` / `privacidade.html` — modelos para preencher

Site estático: na Vercel, importe o repositório com o preset **Other**, sem comando de build.

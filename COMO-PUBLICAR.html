Como colocar o Osso a Osso no ar

Tempo: uns 20 minutos. Você não precisa instalar nada. Arquivos desta pasta:

  • index.html: a página de vendas, com a demonstração jogável e os preços.
  • app.html: a plataforma (login, jogo, progresso e recompensas).
  • config.js: onde você cola as chaves do Supabase.
  • supabase.sql: cria as tabelas de progresso e de recompensas, com as regras de segurança.
  • supabase-recompensas.sql: só a parte das recompensas, para quem já tinha rodado o arquivo anterior.
  • termos.html e privacidade.html: modelos para você preencher.

Já feito por mim: o projeto osso-a-osso (região São Paulo) foi criado, as tabelas e as regras de segurança estão prontas e o config.js já está preenchido. Pule direto para o passo 4.

1Crie o projeto no Supabase

  1. Entre em supabase.com e crie uma conta (pode usar o GitHub ou o e-mail).
  2. Clique em New project. Dê o nome osso-a-osso, crie uma senha para o banco (guarde-a) e escolha a região South America (São Paulo).
  3. Espere uns 2 minutos até o projeto ficar pronto.

2Crie a tabela de progresso

  1. No menu da esquerda, abra SQL Editor e clique em New query.
  2. Abra o arquivo supabase.sql num editor de texto (Bloco de Notas serve), copie tudo e cole lá.
  3. Clique em Run. Deve aparecer "Success. No rows returned".

Já tinha rodado o supabase.sql antes das recompensas? Rode só o arquivo supabase-recompensas.sql do mesmo jeito. Ele cria a tabela de XP, ofensiva e conquistas sem mexer no progresso que já existe.

3Cole as chaves no config.js

  1. No topo do projeto, clique em Connect (ou vá em Project Settings → API Keys).
  2. Copie a Project URL (algo como https://abcd1234.supabase.co) e a Publishable key (começa com sb_publishable_; se só aparecer a anon key, pode usar ela).
  3. Abra config.js no Bloco de Notas e troque os dois textos COLE_AQUI... pelos valores, mantendo as aspas. Salve.

Nunca cole a secret key nem a service_role key no site. A publishable pode ficar pública: quem protege os dados são as regras do passo 2.

4Publique na Netlify

  1. Crie uma conta em netlify.com e entre nela antes (sites enviados sem conta são apagados depois de um tempo).
  2. Abra app.netlify.com/drop e arraste a pasta inteira do site para a área indicada.
  3. Em segundos aparece o endereço do site, tipo https://nome-aleatorio.netlify.app. Em Site configuration → Change site name você pode trocar para ossoaosso.netlify.app, se estiver livre.

5Diga ao Supabase qual é o endereço do site

Sem isso, os links dos e-mails de confirmação e de senha vão para o lugar errado.

  1. No Supabase, abra Authentication → URL Configuration.
  2. Em Site URL, coloque o endereço da Netlify (ex.: https://ossoaosso.netlify.app) e salve.
  3. Em Redirect URLs, adicione o mesmo endereço com /** no fim (ex.: https://ossoaosso.netlify.app/**).

6Teste

  1. Abra o site, clique em Criar conta e cadastre seu e-mail.
  2. Abra o e-mail de confirmação e clique no link: você volta ao site já logado.
  3. Jogue um nível, saia da conta, entre de novo (ou abra no celular): o nível deve aparecer como feito.
  4. Teste o Esqueci minha senha.
  5. No Supabase, em Authentication → Users, você vê quem se cadastrou. Em Table Editor → progresso, o progresso de cada um. Em Table Editor → recompensas, o XP, a ofensiva e as conquistas.

7Antes de divulgar

  • E-mail próprio: o e-mail grátis do Supabase manda só 2 por hora. Crie uma conta no Resend (ou outro serviço de e-mail), e cole os dados em Authentication → Emails → SMTP Settings.
  • E-mails em português: em Authentication → Emails → Templates, troque os textos pelos modelos abaixo.
  • Termos e Privacidade: preencha termos.html e privacidade.html e peça para um advogado revisar.
  • Pausa por inatividade: no plano grátis, o Supabase pausa o projeto depois de 7 dias sem uso. Reative no painel, ou passe para o plano Pro quando tiver usuários.
  • Domínio próprio (opcional): registre em registro.br e ligue na Netlify em Domain management. Depois, atualize o passo 5 com o domínio novo.

Como atualizar o site depois

Mude os arquivos e, na Netlify, abra o site → Deploys → arraste a pasta de novo. O config.js precisa continuar preenchido.
